## ① AI活用支援 × 中小企業

### 市場データ
- 法人向けAI導入支援市場：2024年 ¥330億 → 2025年 ¥503億（前年比152%）
- DXコンサル市場：2025年見込み ¥5,000億
- 中小企業のAI導入率：約25%（4社に3社は未導入）

### Kivaができる具体的なサービス
- 「学生AIチームが御社の業務をAI化します」ワークショップ（¥150k〜/回）
- 業種特化の生成AIプロンプト設計＋実装支援（月次¥100〜200k）
- 補助金（IT導入補助金・ものづくり補助金）と組み合わせた導入支援

### 評価
| 項目 | 評価 |
|------|------|
| 市場の熱さ | ◎ 爆発的成長中 |
| Kivaとの相性 | △ AI技術の習得が先に必要 |
| 参入難易度 | △ 競合が急増している |
| 月100万円の現実性 | ○ 取れるが差別化が難しい |

**判断**：市場は熱いが「AIコンサル」はすでに混雑。Kivaが入るなら「AI×学生共創」という独自フレームが必須。今すぐより6〜12ヶ月後の選択肢。

## ② インバウンド × 地方産品の販売・体験設計

### 市場データ
- 2024年訪日客：3,687万人（過去最高）
- インバウンド消費額：¥8.1兆円（前年比53%増）
- 「モノ消費→コト消費」へのシフト：体験型・ストーリー型商品に需要集中

### Kivaができる具体的なサービス
- 地方メーカー×学生による「インバウンド向けポップアップ」企画・運営代行（¥200〜500k/回）
- 外国語対応パッケージ＋ストーリー設計（学生の語学・デザイン力を活用）
- 越境EC出品代行（訪日できない層へのオンライン販売）

### 評価
| 項目 | 評価 |
|------|------|
| 市場の熱さ | ◎ 円安＋観光ブームで追い風 |
| Kivaとの相性 | ◎「地方の本物を世界へ」ビジョンと直結 |
| 参入難易度 | ○ 語学力のある学生がいれば動ける |
| 月100万円の現実性 | △ 案件単価は高いが単発になりやすい |

**判断**：ビジョンとの相性は最高。ただ月次リテイナーにしにくいので「顧問サービスのオプション」として既存クライアントに提案する形が現実的。

## ③ Z世代キャリア × 地方中小企業への採用支援

### 市場データ
- Z世代の就職軸1位：「スキルアップ・成長の機会」→ 大企業志向が崩れつつある
- プロジェクト型インターン：秋冬は実質的な採用選考として機能
- 地方長期インターン求人：急増中（1,300社以上の掲載実績）

### Kivaができる具体的なサービス
- 「共創プロジェクト経由採用」モデル：共創プロジェクト参加学生をそのままクライアントへ紹介
- 採用成功報酬：¥300〜500k/人（人材紹介業と同水準）
- 採用前提の長期プロジェクト設計支援（月次¥100k〜）

### 評価
| 項目 | 評価 |
|------|------|
| 市場の熱さ | ◎ 採用難で中小企業は本当に困っている |
| Kivaとの相性 | ◎◎ 追加投資ゼロで今すぐできる |
| 参入難易度 | ◎ すでに学生ネットワークがある |
| 月100万円の現実性 | ◎ 成功報酬1件で¥300k〜500k |

**判断**：これが一番おいしい。Kivaはすでに学生と企業を繋いでいる。契約に「採用につながったら成功報酬」を一行加えるだけで新規事業になる。

## ④ 職人・伝統産業 × SNS運用代行

### 市場データ
- 国内SNSマーケティング市場：2024年 約¥860億（前年比116%増）
- 「リアルな現場動画」が最もエンゲージメントが高い時代
- マイクロ・ナノインフルエンサー（フォロワー1万未満）が全体の76%

### Kivaができる具体的なサービス
- 職人・地方メーカーのSNSアカウント設計＋学生チームによる運用代行（月次¥80〜150k）
- 「職人ドキュメンタリー動画」制作（TikTok・Reels・YouTube Shorts）
- 海外発信特化プラン（英語・中国語字幕付き、インバウンド連動）

### 評価
| 項目 | 評価 |
|------|------|
| 市場の熱さ | ◎ SNS運用代行需要は爆発的 |
| Kivaとの相性 | ◎「プロセスを隠さない」哲学と完全一致 |
| 参入難易度 | ○ 動画制作スキルのある学生が必要 |
| 月100万円の現実性 | ○ 8〜10社の月次契約で達成可能 |

**判断**：Kivaの「ドキュメンタリー的に切り取る」ビジュアル哲学と直球で合う。単価が低め（¥80〜150k）なので件数が必要だが、学生に任せやすく2名の稼働負荷が低い。
