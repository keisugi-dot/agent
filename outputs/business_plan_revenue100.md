# Kiva 月次収益100万円達成ビジネスプラン
> 作成日: 2025年（2名体制 × 最小リソース × 最大利益率）

---

## エグゼクティブサマリー

2名で月100万円以上の安定収益を実現するための**「共創顧問サービス」モデル**。

- **コアモデル**: 企業との月次顧問契約（リテイナー型）
- **価格**: 1社あたり ¥200,000〜¥250,000 / 月
- **目標契約数**: 4〜5社で ¥800k〜¥1.25M/月
- **なぜ2名で回せるか**: 学生が実行部隊（ガクチカ目的で稼働）、Kivaは「設計と管理」に集中
- **粗利率**: 70〜80%（学生コストが最小限のため）

---

## 発見した「もったいない」

- 中小企業・アトツギ企業には「新しいことをやりたい」熱意があるが、
  企画・実行するリソースが社内にない
- 外部に頼もうとすると、コンサルは「高い・納品して終わり」、
  制作会社は「形は作るが中身に関与しない」という選択肢しかない
- **Kivaが埋める空白**: 「月2回来てくれて、学生も連れてきて、プロトタイプまで作ってくれる伴走者」
  ← 社員を1人雇うより安く、コンサルより泥臭く動く

## 収益モデル詳細

### ■ Main Revenue: 共創顧問サービス（月次リテイナー）

| 項目 | 内容 |
|------|------|
| **契約形態** | 月次顧問契約（最低3ヶ月〜） |
| **価格** | ¥200,000 〜 ¥250,000 / 月 |
| **クライアントへの価値** | ① 月1回の共創ワークショップ（学生5〜8名参加）<br>② 月次ブランド・プロダクト開発サポート<br>③ 学生チームのプロジェクト管理代行<br>④ 社内では動けないアイデアの「実装の壁」突破支援 |
| **Kivaの稼働** | 1クライアントあたり月3〜4日（ワークショップ1日＋準備・管理2〜3日） |
| **学生コスト** | ガクチカ（実績）交換が主軸。交通費＋謝礼として1日¥3,000〜¥5,000程度 |

```
【収益シミュレーション】

クライアント数  月次売上      Kiva稼働日数（2名合計）
─────────────────────────────────────────────────
2社          ¥400,000      8〜10日  ← スタート期
3社          ¥600,000      12〜14日 ← 3ヶ月目目標
4社          ¥800,000      16〜18日 ← 月100万円圏内
5社          ¥1,000,000+   20〜22日 ← 安定目標
─────────────────────────────────────────────────
```

**→ 4社 ¥200k = ¥800k ＋ 追加オプション（下記）で ¥100万円突破**

---

### ■ Sub Revenue: オプション追加収益

| オプション | 単価 | 頻度 | 月次換算 |
|-----------|------|------|---------|
| Micro-Make実行（プロトタイプ製造代行） | ¥150,000〜¥300,000/回 | 月1回程度 | +¥150k〜¥300k |
| 成果物パッケージ（ブランドガイドライン等） | ¥100,000〜¥200,000/件 | 随時 | +¥50k〜¥100k |
| テスト販売サポート（POPUP・CF設計） | ¥80,000〜¥150,000/回 | 月1〜2回 | +¥80k〜¥150k |

**→ 顧問4社 ＋ Micro-Make1件 = ¥950,000〜¥1,100,000/月 達成**

## ターゲットクライアント

### 最優先ターゲット：アトツギ企業（後継ぎ）

**なぜアトツギか：**
- 「先代から継いだが、自分の代で変革したい」という強烈な熱意がある
- 既存事業が回っているため、月¥200kの支出予算がある
- 「若い感覚で刷新したい」という理由で、学生との共創に親和性が高い
- 全国に組織化されている（後継ぎ甲子園・各地商工会議所）

**セカンドターゲット：中小メーカーの新規事業担当**
- 良い素材・技術があるが、D2C・ブランディングのノウハウがない
- 社内稟議を通るための「外部の力」として使いやすい

## Mobilize → Micro-Make → Passion の月次サイクル設計

### 月次スケジュール（クライアント1社分）

```
Week 1: ワークショップ（Kiva 2名 ＋ 学生5〜8名、3〜4時間）
         └── 企業の「もったいない」を引き出す → アイデア発散

Week 2: アイデア絞り込み & 仮説設計（Kiva主導、1〜2日）
         └── 最有望案を3つ → 1つに絞る

Week 3: 学生による素材整理・試作設計（学生チーム主導 ＋ Kivaが遠隔管理）

Week 4: 月次進捗報告・次月計画（Kiva 0.5日）
         └── クライアントとの信頼構築 → 継続率UP
```

**2名のロール分担：**
- Keita：クライアントリレーション・ワークショップファシリテーション・事業戦略
- もう1名：学生マネジメント・プロジェクト進行管理・コンテンツ制作

## クライアント獲得戦略（最初の4社を取りにいく）

### Phase 1：既存ネットワーク（0→2社）— 1〜2ヶ月目

1. **「米と出汁。」経験から繋がった企業・生産者** → 直接提案
2. **Kivaがこれまで関わった企業・学校** → 「新サービスの先行モニター」として声がけ
3. **2社限定、3ヶ月モニター価格（¥150k/月）** → 実績・事例作成

### Phase 2：アトツギネットワーク（2→4社）— 2〜4ヶ月目

1. **後継ぎ甲子園・各地アトツギ交流会** への登壇・参加
2. **商工会議所の新規事業相談窓口**との連携（紹介制）
3. **SNS発信**：ワークショップの熱量・プロセスをドキュメンタリー的に発信
   → 「こんな動き方があるのか」という認知獲得

### 提案時の刺さるフレーム

```
「社員1人を雇う前に、まず月¥20万で試してみませんか。
 学生チームと一緒に、3ヶ月でプロトタイプまで作ります。
 もし刺さらなければ止めればいい。
 でも、やらなかった後悔の方が絶対に大きいはずです。」
```

## フェーズ別ロードマップ

### Phase 1：体力作り（Month 1〜2）目標: ¥400〜600k/月

- [ ] モニタークライアント2社獲得（既存ネットワーク）
- [ ] ワークショップのフォーマット固定化（型を作る）
- [ ] 学生リクルートパイプライン構築（大学の窓口・SNS）
- [ ] 成果事例の可視化・SNS発信開始

### Phase 2：安定基盤（Month 3〜4）目標: ¥800k〜1M/月

- [ ] 本価格（¥200k〜）での4社目まで獲得
- [ ] クライアント継続率80%以上の維持
- [ ] Micro-Make案件1件/月の定常化
- [ ] 毎月のプロセスをコンテンツ化（月次事例発信）

### Phase 3：新規事業投資（Month 5〜）目標: ¥1.2M+ × 新規事業並走

- [ ] 顧問5社体制で月¥1M安定
- [ ] 余剰利益でD2Cプロダクト開発（「米と出汁。」モデルの横展開）
- [ ] 学生コミュニティをKivaブランドの発信基地として活用
- [ ] 海外展開（日本の地方の本物を世界へ）の試行

## リスクと対策

| リスク | 対策 |
|--------|------|
| クライアントが途中解約する | 最低3ヶ月契約 ＋ 1ヶ月ごとに「成果の可視化レポート」を提出し続ける |
| 2名の稼働がオーバーする | 4社超えたら単価を上げる（¥250k〜¥300k）か、学生サポーターを専任化 |
| 学生の質・継続が不安定 | 大学2〜3校との定期連携を作る。ガクチカ実績の明文化で報酬化 |
| 良いクライアントが来ない | 最初の2社の成果を全公開する（啓太哲学：プロセスを隠さない） |
