# Kiva 月次収益100万円達成ビジネスプラン（副業スタート版）
> 作成日: 2025年 | 2名・副業体制 → 段階的フルコミット移行

---

## 前提条件

| 項目 | 内容 |
|------|------|
| メンバー | 2名（現在は副業として稼働） |
| 稼働可能時間 | 平日夜＋土日（本業がある間） |
| 目標 | 副業収益で月100万円を安定させ、フルコミットへの移行判断を行う |
| 移行トリガー | 月収益が3ヶ月連続で目標を超えたタイミングで本業を離脱 |

---

## エグゼクティブサマリー

副業でも回せるモデルに絞り込む必要がある。
**カギは「稼働時間を最小化しながら高単価を取る設計」**。

- コアモデル：**週末集中型の共創顧問サービス**
- 価格：1社あたり ¥150,000〜¥200,000 / 月
- 目標契約数：副業期 2〜3社 → フルコミット後 5社へ
- なぜ副業で回せるか：ワークショップは月1回（土日）、管理は学生に委譲

---

## 発見した「もったいない」

副業でも月100万円を目指す人・企業はたくさんいるのに、
「本業を持ちながら新規事業を動かしてくれるパートナー」はほぼ存在しない。

→ Kivaの「副業でも泥臭く伴走する」姿勢そのものが差別化になる。
  「本業がある中でこれだけやってくれるなら、フルになったらもっとやってくれる」という信頼構築にもなる。

## 副業期の現実的な稼働設計

### 1ヶ月の使える時間（2名合計）

```
平日夜（2〜3時間 × 20日）  = 40〜60時間
土日（6〜8時間 × 8日）     = 48〜64時間
──────────────────────────────────────
合計                       ≈ 90〜120時間 / 月（2名）
```

### 1クライアントあたりの必要時間

```
ワークショップ（月1回・土日）    8時間
準備・資料作成                   4時間
学生チーム管理・連絡              6時間
クライアント報告・打ち合わせ      4時間
──────────────────────────────────────
合計                           ≈ 22時間 / 月
```

**→ 2名で90〜120時間 ÷ 22時間 = 4〜5社は理論上可能だが、副業期は2〜3社に抑える（品質と精神的余裕を守る）**

## 収益シミュレーション

### 副業フェーズ（2〜3社）

```
【2社 × ¥180,000 = ¥360,000 / 月】
  変動費（学生謝礼・交通費等）  ▲¥60,000
  ──────────────────────────────────────
  粗利                        ¥300,000
  ※ 2名で分配すると ¥150,000 / 人
  ※ 本業収入と合わせて生活は成立する状態
```

```
【3社 × ¥200,000 = ¥600,000 / 月】
  変動費                      ▲¥80,000
  ──────────────────────────────────────
  粗利                        ¥520,000
  ※ 本業収入と合わせると月収がかなり上がる
  ※ フルコミットの検討を始めるライン
```

### フルコミット移行後（4〜5社）

```
【5社 × ¥220,000 = ¥1,100,000 / 月】
  変動費                      ▲¥130,000
  固定費（法人運営等）         ▲¥100,000
  ──────────────────────────────────────
  営業利益                    ¥870,000
  ※ 2名で分配 → ¥435,000 / 人
  ※ Micro-Make案件が加わると更に上積み
```

## フルコミット移行の判断基準

感情や焦りではなく、数字で判断する。

```
移行トリガー（以下を全て満たしたら本業を離脱）:
  □ 月収益が ¥600,000 以上 × 3ヶ月連続
  □ 既存クライアント2社以上が3ヶ月継続している（継続性の証明）
  □ 手元に3ヶ月分の生活費が確保できている
  □ 次の新規クライアントの見込みが1社以上ある
```

## 副業期にやること・やらないこと

### やること ✅

- **土日ワークショップに集中する**（本業に影響しない時間帯で完結）
- **学生チームへの権限委譲を最初から設計する**（自分が動かなくても回る仕組み）
- **クライアント1社ごとに事例をSNSで発信する**（副業中でも認知は積み上げる）
- **小さく始めて3ヶ月で実績を作る**（最初の1社はモニター価格 ¥120k でもいい）

### やらないこと ❌

- 平日昼に稼働が必要な仕事（本業がある間は受けない）
- 低単価のスポット案件（時間対効果が悪い）
- 一度に3社以上の新規クライアント開拓（品質が崩れる）
- Micro-Make（プロトタイプ製造）の実行 ← フルコミット後に解禁

## 副業期のターゲットクライアント（絞る）

### 最優先：週末に動けるアトツギ企業

- 担当者がある程度フレキシブルに動ける企業（小規模・オーナー系）
- 「月1回の土日ワークショップ」に合意してくれる相手
- 意思決定が早い（大企業の新規事業部門は稟議が長くNG）

### 提案時のフレーム（副業であることを逆手に取る）

```
「私たちも今、本業を持ちながらこれに全力で取り組んでいます。
 だから、御社の担当者さんが忙しい中で動いている感覚、よくわかります。
 まず月1回の土日から始めましょう。それだけで3ヶ月後には形が見えます。」
```

## 段階的移行ロードマップ

### Stage 0：今すぐ（副業開始）
- [ ] 既存ネットワークから声をかけられる企業を10社リストアップ
- [ ] モニター価格（¥120,000/月 × 3ヶ月）で1社目を獲得
- [ ] 土日ワークショップのフォーマットを1枚にまとめる
- [ ] 学生リクルートを1校以上と関係を作る

### Stage 1：Month 1〜3（副業 2社・¥360k/月）
- [ ] 1社目のワークショップを実施し、事例化・SNS発信
- [ ] 2社目を本価格（¥180k〜）で獲得
- [ ] 学生チームの自走率を上げる（Kivaなしでもタスクが進む状態）

### Stage 2：Month 4〜6（副業 3社・¥600k/月）
- [ ] 移行トリガーの数字を毎月チェック
- [ ] 3社目獲得 → ¥600k/月ラインへ
- [ ] フルコミット後の4〜5社目の見込み客を育てておく

### Stage 3：フルコミット（Month 6〜12・5社・¥1M+/月）
- [ ] 本業離脱（数字トリガー達成後）
- [ ] Micro-Make案件の追加で月次収益を上積み
- [ ] 新規事業（D2C・海外展開）への投資を開始

## リスクと対策

| リスク | 対策 |
|--------|------|
| 本業との両立で疲弊する | 3社を超えない。学生に実行を任せる設計を徹底する |
| クライアントが「副業でやってる」ことに不安を感じる | 隠さず伝える（「だからこそ本気でやっています」と正直に）。プロセスを全部見せる |
| 移行タイミングを見誤る | 感情ではなく上記の数字トリガーを厳守する |
| 副業規定に引っかかる | 法人格（Kiva）名義での活動として整理する |
