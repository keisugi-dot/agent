# Kiva 新規事業 競合調査レポート

## ① AI活用支援 × 中小企業

### 市場独占度：◎ 分散（今が最も参入しやすいタイミング）

### 主要競合

| プレイヤー | 特徴 | 料金 |
|---|---|---|
| NTTデータ / Ridgelinez | 大企業向け、中小には来ない | 数百万〜 |
| SHIFT AI for Biz | 研修+ワークショップ型、2,500社実績 | 要問合せ（個人55万円〜） |
| neoAI / ELYZA（東大松尾研発） | 技術系スタートアップ | 要問合せ |
| AI任せ太郎（アリスタイル） | 中小向けスモールスタート | 月額5〜30万円 |
| ランサーズ / ココナラ | フリーランスマーケット | 数万円〜 |

### 模倣すべき成功事例

- **EQUES「AI顧問」モデル** — 月額20万円のチャット相談から始めてPoC(250万円〜)に誘導する2段階設計
- **SHIFT AI for Biz** — 「研修→自走」の型。Kivaなら学生が直接手を動かす「伴走型・格安版」として月額5〜10万円帯で参入できる

### 評価
- 独占プレイヤー不在、「格安・伴走型・スモールスタート」ゾーンはほぼ空白
- ただし技術的信頼の積み上げが先に必要
- **推奨：6〜12ヶ月後の選択肢として温存**

## ② インバウンド × 地方産品の販売・体験設計

### 市場独占度：○ やや分散（「地方産品×ポップアップ一気通貫」は空白地帯）

### 主要競合

| プレイヤー | 特徴 | 料金 |
|---|---|---|
| アソビュー / Viator（TripAdvisor） | 体験予約OTA、集客力は最強 | 手数料20〜30% |
| LIFE PEPPER | 1,000社以上の海外デジタルマーケ支援 | 月額数十万円〜 |
| インパクトフィールド | 百貨店・催事・ポップアップ運営代行 | スタッフ派遣型 |
| byFood（テーブルクロス） | 食体験×産品購入ファネル設計 | 手数料型 |
| Origami Concierge | 富裕層向け体験、自治体連携 | スタートアップ |

### 模倣すべき成功事例

- **Origami Concierge** — 愛媛県で体験30件を造成→ドバイ富裕層誘客に成功。「外国人コミュニティを先に作ってから商品設計に巻き込む」逆算アプローチ
- **byFood** — 「体験で感動 → 産品購入 → EC継続購入」の3ステップファネル

### 評価
- 「地方産品×インバウンド×ポップアップ一気通貫」の専業プレイヤーはほぼ存在しない
- アソビュー等の大手OTAは集客は強いが現場運営・産品ストーリー設計には弱い
- 単発案件になりやすく月次リテイナー化が課題
- **推奨：既存顧問クライアントへのオプション追加として提案**

## ③ Z世代キャリア × 採用支援

### 市場独占度：○ やや分散（地方×プロジェクト型×採用直結の専業は不在）

### 主要競合

| プレイヤー | 特徴 | 料金 |
|---|---|---|
| **G-net（岐阜）** | 20年の老舗NPO「ホンキ系インターン」。東海圏最強 | 非公開（要問合せ） |
| PROJECT INDEX | 検索プラットフォーム型、伴走なし | 掲載費 |
| Wantedly | 共感採用型SNS、インターン〜中途対応 | 月額6〜22万円 |
| ゼロワンインターン | 長期インターン求人サイト最大手 | 成功報酬8.8万円/人〜 |
| キャリアバイト | **2026年3月23日でサービス終了** | - |

### 模倣すべき成功事例

- **G-net「ホンキ系インターン」** — 「企業の経営課題を言語化してプロジェクト化する」コーディネーター機能が価値の本質。累計880名コーディネート、採用117名、定着率74%
- **G-net「ミギウデ」** — インターン→正規雇用の定着率をKPIにしてブランド化

### 今すぐ動ける理由

1. **キャリアバイトが2026年3月終了** → 長期インターン掲載市場に穴が開いた今がチャンス
2. **採用直結インターンの制度解禁（2023〜）** → Kivaの「共創→採用」モデルが制度的に正当化された

### G-netとの差別化

G-netは東海圏中心のNPO。Kivaはオンライン×デジタルで全国展開が可能。
「プロジェクト設計テンプレ＋オンラインマッチング＋採用後フォロー」をセット化するとG-netにないポジションが取れる。

### 評価
- **現時点で最も参入余地が大きく、既存リソースで今すぐ動ける**
- 成功報酬¥300〜500k/人は現実的
- **推奨：最優先で着手**

## ④ 職人・伝統産業 × SNSブランディング

### 市場独占度：○ やや分散（「職人特化のSNS運用代行単体」は空白地帯）

### 主要競合

| プレイヤー | 特徴 | 料金 |
|---|---|---|
| **物語運輸** | 職人の動画+越境EC一体型。Kickstarterで2080%達成。シード調達済み | 非公開 |
| **CRAFT STORE（ニューワールド）** | 伝統工芸×EC動画、2016年設立の老舗 | 非公開 |
| 汎用SNS代行（Zero-One等） | 伝統産業への専門性なし | 月額30〜65万円 |

### 物語運輸との重なりについて

物語運輸は「EC販売が主軸で、動画はその手段」というモデル。
「SNS運用だけやってほしい」「TikTok/Reelsのフォロワーを増やしたい」という職人のニーズには対応していない。
**棲み分けは可能**だが、「物語を語る」というコアの哲学は完全に被る。

Kivaが参入するなら差別化軸：
- EC販売なし・SNS特化
- 学生の視点で切り取る臨場感・リアルさ
- 月額10〜30万円の低価格帯（物語運輸の参入できないゾーン）

### 評価
- 物語運輸はビジョンの哲学が近い（将来的に連携・統合の可能性もある相手）
- 「EC連携しない、動画・SNS運用のみ特化」で差別化は可能
- 地方職人の予算感（月額20〜30万円は重い）が課題
- **推奨：動ける学生が1人いれば今すぐ始められる。物語運輸との差別化を明確化すること**
